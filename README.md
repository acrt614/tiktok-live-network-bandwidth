## “TikTok 网络专线”在不同商家嘴里是两样东西

YouTube 上做网络教程的“不良林”在 2023 年拆过这门生意。他朋友花 180 元/月买了一个“TK 节点”，用域名反查工具看到同一个域名下绑了将近 700 个独立 IP，而对应 VPS 的成本大约 30 元/月。按每个节点每月赚 100 元保守估算，一个月七万。这是三年前的个案数字，今天具体差价未必一样，但逻辑没变：多数所谓 TikTok 专线，就是普通 VPS 线路加一层场景包装，跟 IPLC、IEPL 那种点对点专线不是一回事。国内技术社区里讲自建 VPS 的文章也说得很清楚，独享网络不等于真正的专线，线路质量和 SD-WAN 专线之间存在技术差距。

这对买家的意义不是“别买”，而是“买之前自己查一遍”。三个动作，十分钟能做完：

1. **查 ASN 类型**。把 IP 丢进 ipinfo.io，看 ASN 的 type 字段。显示 hosting 就是机房托管 IP，显示 isp 更接近本地宽带用户。“不良林”当时实测那个热销节点，类型就是 hosting，说明运营 TikTok 不一定非住宅 IP 不可。
2. **查欺诈分**。scamalytics.com 输入 IP 看风险评分。分数低不代表一定好用，分数高也不必然影响你的业务，但可以作为横向比较的参考。
3. **看这个 IP 被多少人共用**。机场节点几十上百人共用同一个出口，刷视频可能没事，发视频和开直播容易 0 播放。这是自建或独享 IP 的核心价值所在。

WePC 的产品命名本身就透露了一部分信息：写着“家宽”“双 ISP”的和写着“原生 IDC”的是两类东西，新加坡那款直接标了 IDC 非家宽。它没有把机房 IP 包装成住宅 IP 卖，这一点比很多转售商诚实。反过来也要注意，家宽 IP 不等于线路好，韩国款写着“联通绕路”、西班牙款写着“必须加中转才能正常”，这些提示都是商家自己写的。

## 直播到底要多大带宽

按设备分，手机 TikTok 直播建议 **5M 起步**，电脑直播建议 **10M 起步**；720P 大致需要 4Mbps 以上上传，1080P 尽量做到 10Mbps 以上，1080P 高清直播则建议 10–20Mbps 或更高。这里的 5M 指直播业务能稳定使用的带宽，不是测速软件偶尔跳到 5Mbps 的峰值。

多设备不能简单共享一条 5M。VDEnet 在产品页给出的换算口径是：5M 带宽理论上支持 1 台手机直播加 1 台手机运营，10M 支持 3 台手机直播加 2 台手机运营。团队多直播间就该按“同时在线设备数 × 单设备需求”往上加，再留冗余，20M、50M 的方案对应的是这种规模。

| 场景 | 建议可用上行 | 说明 |
| --- | --- | --- |
| 单台手机、720P 真人出镜 | 5Mbps 起 | 网络稳定比数字大小更重要 |
| 单台手机直播 + 1 台运营机 | 5–10Mbps | 两台设备共用一条线要留余量 |
| 电脑 OBS / LIVE Studio，720P | 4Mbps 以上，建议 10Mbps | 推流软件可调码率，码率越高越吃上传 |
| 电脑 1080P 30fps | 10–20Mbps | 画面变化快的场景往 20Mbps 靠 |
| 3 台手机同时直播 + 2 台运营 | 10Mbps 起，实际建议 20Mbps 以上 | 厂商换算的临界值，不适合卡着用 |
| 多直播间团队 | 20M、50M 或更高 | 按机位数量线性叠加 |

回到 WePC 的表格，100Mbps、200Mbps 是端口规格，是这台机器网卡的上限，跟 TikTok 推流吃掉的 5–20Mbps 不是一个口径。端口 200Mbps 的便宜款在晚高峰照样可能卡，卡不卡取决于回程线路质量、丢包和抖动，这也是为什么同一家店里 9929、4837 优化线路的款会贵几澳元。

## 三个容易漏算的条款

**双向流量。** WePC 全线标的是“双向流量”，上行下行都计入额度。直播是持续上传，2TB 看着多，实际消耗速度取决于码率和时长。MKCloud 在自己的说明里提示过，双向计费下直播用户 2TB 可能半个月用完。马来西亚那款还多写了一句“超流量限速 5M”，跑到限速之后，5M 刚好卡在单手机直播的下限，能播但没有任何余量。

**中转成本。** 表里超过一半的款写着“建议中转”或“必须中转”。中转要么另买一条国内到入口的优化线路，要么用现成机场，后者多人共用同一出口 IP，用在直播上容易踩前面说的那个坑。AUD$10.90 的入门款不等于总成本 10.90，把中转的钱和配置时间算进去再对比。想要开箱直连的，就看页面明写“无需中转”的那几款，美国 4837 和 9929 线路都在这个范围内。
